## Détail des exercices

### Presse à cuisses

**Presse à cuisses** · Quadriceps, fessiers, ischio-jambiers · Débutant  
Réglages : Dossier réglé pour qu’en bas les hanches restent collées au siège. Pieds au milieu de la plateforme, largeur de hanches. Déverrouille les sécurités une fois en place, reverrouille à la fin.  
Consignes : Pieds à plat, genoux dans l’axe des pointes de pieds. / Descends jusqu’à environ 90° aux genoux, le bas du dos reste collé. / Pousse dans tout le pied, sans verrouiller les genoux en haut.  
Erreur fréquente : Descendre trop bas : le bassin s’enroule et le bas du dos décolle du dossier.  
Si la machine est prise : Squat à la Smith machine

**Presse à cuisses pieds hauts** · Fessiers, ischio-jambiers, quadriceps · Intermédiaire  
Réglages : Pieds en haut de la plateforme, un peu plus larges que les hanches, pointes légèrement ouvertes.  
Consignes : Talons bien posés pendant tout le mouvement. / Descends en gardant les genoux ouverts vers les pointes. / Pousse par les talons et serre les fessiers en haut.  
Erreur fréquente : Laisser les talons décoller : la charge repart sur les genoux.  
Si la machine est prise : Hip thrust à la Smith machine

**Presse à cuisses une jambe** · Quadriceps, fessiers (une jambe après l’autre) · Intermédiaire  
Réglages : Un pied au centre de la plateforme, l’autre posé au sol ou sur le cadre. Charge réduite de plus de moitié.  
Consignes : Genou dans l’axe du pied, sans rentrer vers l’intérieur. / Amplitude plus courte qu’à deux jambes, bassin immobile. / Toutes les répétitions d’un côté, puis l’autre.  
Erreur fréquente : Garder la charge des deux jambes : le bassin tourne pour compenser.  
Si la machine est prise : Fente à la Smith machine

**Mollets à la presse** · Mollets · Débutant  
Réglages : Jambes tendues sans verrouiller, seul l’avant des pieds sur le bas de la plateforme. Sécurités verrouillées si la machine le permet.  
Consignes : Talons dans le vide, descends-les lentement. / Pousse sur l’avant des pieds le plus haut possible. / Marque une seconde en haut.  
Erreur fréquente : Plier les genoux pour aider : ce sont alors les cuisses qui poussent.  
Si la machine est prise : Mollets debout à la Smith machine

### Leg extension

**Leg extension** · Quadriceps · Débutant  
Réglages : Dossier réglé pour que le genou soit en face de l’axe de rotation (repère de couleur). Boudin juste au-dessus des chevilles.  
Consignes : Fesses au fond du siège, mains sur les poignées. / Tends les jambes en une seconde, marque l’arrêt en haut. / Redescends en deux ou trois secondes, sans laisser tomber la charge.  
Erreur fréquente : Genou décalé de l’axe de la machine : le mouvement tire sur le genou.  
Si la machine est prise : Presse à cuisses

**Leg extension une jambe** · Quadriceps (une jambe après l’autre) · Débutant  
Réglages : Mêmes réglages qu’à deux jambes, environ la moitié de la charge.  
Consignes : Une seule jambe sous le boudin, l’autre pliée. / Monte en contrôlant, sans élan du buste. / Compare les deux côtés : même nombre de répétitions.  
Erreur fréquente : Se servir du buste pour lancer la charge.  
Si la machine est prise : Presse à cuisses une jambe

### Leg curl assis

**Leg curl assis** · Ischio-jambiers · Débutant  
Réglages : Genou en face de l’axe. Boudin bas sous les mollets, juste au-dessus des talons. Barre de maintien serrée sur le haut des cuisses.  
Consignes : Dos collé au dossier. / Ramène les talons sous le siège en une à deux secondes. / Remonte lentement jusqu’aux jambes presque tendues.  
Erreur fréquente : Barre de cuisses trop lâche : les hanches se soulèvent et le dos travaille.  
Si la machine est prise : Leg curl allongé

### Leg curl allongé

**Leg curl allongé** · Ischio-jambiers · Débutant  
Réglages : Allongé sur le ventre, genoux juste après le bord du banc, boudin sur l’arrière des chevilles.  
Consignes : Hanches plaquées contre le banc. / Ramène les talons vers les fesses sans à-coup. / Redescends en trois secondes.  
Erreur fréquente : Décoller les hanches pour finir le mouvement.  
Si la machine est prise : Pont fessier

### Abducteurs et adducteurs

**Abducteurs à la machine** · Moyen fessier, haut des fessiers · Débutant  
Réglages : Coussins contre l’extérieur des genoux. Levier de départ réglé jambes serrées.  
Consignes : Dos contre le dossier, mains sur les poignées. / Écarte les genoux en contrôlant, marque l’arrêt. / Reviens sans laisser les plaques se toucher.  
Erreur fréquente : Écarter d’un coup et laisser revenir sans freiner.  
Si la machine est prise : Abduction de hanche à la poulie

**Adducteurs à la machine** · Adducteurs (intérieur des cuisses) · Débutant  
Réglages : Coussins contre l’intérieur des genoux. Écartement de départ confortable, sans étirement forcé.  
Consignes : Dos contre le dossier. / Serre les genoux l’un vers l’autre en une seconde. / Ouvre lentement jusqu’à l’écartement de départ.  
Erreur fréquente : Régler un écartement de départ trop grand : on tire sur l’aine.  
Si la machine est prise : Fente à la Smith machine

### Machine à fessiers

**Extension de hanche à la machine** · Grand fessier, ischio-jambiers · Débutant  
Réglages : Buste sur l’appui, avant-bras sur les poignées, pied de travail à plat sur la plaque.  
Consignes : Dos plat, ventre serré. / Pousse vers l’arrière avec le talon jusqu’à la hanche tendue. / Ne cambre pas en fin de mouvement.  
Erreur fréquente : Monter la jambe trop haut en creusant le bas du dos.  
Si la machine est prise : Extension de hanche à la poulie basse

### Machine à mollets

**Mollets debout à la machine** · Mollets · Débutant  
Réglages : Épaulières à une hauteur où tu es jambes tendues, avant des pieds sur la marche.  
Consignes : Genoux tendus sans être verrouillés. / Descends les talons sous la marche. / Monte sur la pointe des pieds et marque l’arrêt.  
Erreur fréquente : Rebondir en bas au lieu de contrôler.  
Si la machine est prise : Mollets debout à la Smith machine

### Développé assis (chest press)

**Développé assis à la machine** · Pectoraux, avant des épaules, triceps · Débutant  
Réglages : Siège réglé pour que les poignées soient au milieu de la poitrine. Si la machine a une pédale, appuie dessus pour amener les poignées vers toi sans forcer.  
Consignes : Omoplates serrées et collées au dossier. / Pousse en soufflant jusqu’aux bras presque tendus. / Reviens lentement, coudes un peu sous les épaules.  
Erreur fréquente : Siège mal réglé : les épaules montent et s’enroulent vers l’avant.  
Si la machine est prise : Développé couché à la Smith machine

**Développé assis un bras** · Pectoraux, épaules, triceps, gainage · Intermédiaire  
Réglages : Mêmes réglages, une seule poignée, la main libre sur la cuisse.  
Consignes : Le buste ne tourne pas. / Pousse droit devant toi. / Même nombre de répétitions de chaque côté.  
Erreur fréquente : Tourner le buste pour pousser plus loin.  
Si la machine est prise : Pompes

### Développé incliné à la machine

**Développé incliné à la machine** · Haut des pectoraux, avant des épaules, triceps · Débutant  
Réglages : Siège réglé pour que les poignées partent à hauteur du haut de la poitrine.  
Consignes : Dos et tête contre le dossier. / Pousse vers le haut et l’avant, poignets droits. / Reviens jusqu’à sentir l’étirement des pectoraux, pas plus.  
Erreur fréquente : Décoller les fesses du siège pour pousser.  
Si la machine est prise : Développé incliné à la Smith machine

### Pec deck (butterfly et oiseau)

**Écarté à la machine (butterfly)** · Pectoraux · Débutant  
Réglages : Siège réglé pour que les poignées soient à hauteur d’épaules. Bras ouverts sans dépasser la ligne du dos.  
Consignes : Coudes légèrement fléchis, toujours au même angle. / Ramène les mains l’une vers l’autre devant la poitrine. / Ouvre lentement sans tirer sur l’avant des épaules.  
Erreur fréquente : Ouvrir trop loin en arrière : l’avant de l’épaule force.  
Si la machine est prise : Écarté aux poulies de haut en bas

**Oiseau à la machine (pec deck inversé)** · Arrière des épaules, haut du dos · Débutant  
Réglages : Assis face au dossier, poitrine contre l’appui. Bras de la machine réglés en position avant.  
Consignes : Bras presque tendus, à hauteur d’épaules. / Ouvre les bras vers l’arrière en serrant les omoplates. / Reviens lentement devant toi.  
Erreur fréquente : Hausser les épaules : ce sont alors les trapèzes qui travaillent.  
Si la machine est prise : Face pull

### Développé épaules à la machine

**Développé épaules à la machine** · Épaules, triceps · Débutant  
Réglages : Siège réglé pour que les poignées partent à hauteur des épaules.  
Consignes : Dos collé au dossier, ventre serré. / Pousse vers le haut sans verrouiller les coudes. / Redescends à hauteur d’oreilles.  
Erreur fréquente : Cambrer le bas du dos pour pousser plus lourd.  
Si la machine est prise : Développé épaules assis à la Smith machine

### Élévations latérales à la machine

**Élévations latérales à la machine** · Milieu des épaules · Débutant  
Réglages : Siège réglé pour que tes épaules soient en face des axes de la machine. Coussins contre l’extérieur des bras.  
Consignes : Poitrine contre l’appui. / Monte les coudes jusqu’à hauteur d’épaules. / Redescends en trois secondes.  
Erreur fréquente : Monter au-dessus des épaules en haussant les trapèzes.  
Si la machine est prise : Élévation latérale à la poulie

### Tirage vertical (lat pulldown)

**Tirage vertical** · Grand dorsal, biceps, bas des trapèzes · Débutant  
Réglages : Boudins calés sur le haut des cuisses, pieds à plat. Barre longue, mains un peu plus larges que les épaules.  
Consignes : Buste légèrement incliné en arrière, poitrine haute. / Tire la barre vers le haut de la poitrine en descendant les coudes. / Remonte jusqu’aux bras presque tendus, en contrôlant.  
Erreur fréquente : Se balancer en arrière pour tirer : c’est l’élan qui fait le travail.  
Si la machine est prise : Traction assistée

**Tirage vertical prise serrée** · Grand dorsal, biceps · Débutant  
Réglages : Poignée en V (prise neutre) à la place de la barre longue.  
Consignes : Coudes près du corps. / Tire la poignée vers le sternum. / Remonte lentement, épaules basses.  
Erreur fréquente : Enrouler les épaules vers l’avant en fin de mouvement.  
Si la machine est prise : Rowing un bras à la poulie

**Tirage vertical prise inversée** · Grand dorsal, biceps · Intermédiaire  
Réglages : Barre longue, paumes vers toi, mains largeur d’épaules.  
Consignes : Poitrine haute. / Coudes vers les hanches, la barre vers le haut de la poitrine. / Remonte bras presque tendus.  
Erreur fréquente : Tirer avec les bras seulement, le dos reste passif.  
Si la machine est prise : Rowing assis

### Rowing assis

**Rowing assis** · Milieu du dos, grand dorsal, biceps · Débutant  
Réglages : Siège réglé pour que les poignées soient à hauteur du bas de la poitrine ; appui poitrine à une distance où les bras sont tendus.  
Consignes : Buste droit, poitrine contre l’appui (ou dos droit sur la poulie basse). / Tire les coudes vers l’arrière en serrant les omoplates. / Reviens bras tendus, épaules qui avancent sans s’enrouler.  
Erreur fréquente : Basculer le buste en arrière à chaque répétition.  
Si la machine est prise : Rowing un bras à la poulie

**Rowing assis prise large** · Haut du dos, arrière des épaules · Intermédiaire  
Réglages : Poignées larges, coudes à hauteur d’épaules.  
Consignes : Coudes écartés. / Tire vers le haut de la poitrine. / Serre les omoplates une seconde.  
Erreur fréquente : Hausser les épaules en tirant.  
Si la machine est prise : Oiseau à la machine (pec deck inversé)

### Curl biceps à la machine

**Curl biceps à la machine** · Biceps · Débutant  
Réglages : Siège réglé pour que l’arrière des bras soit à plat sur le pupitre, coudes en face de l’axe.  
Consignes : Bras posés tout du long. / Monte les poignées sans décoller les coudes. / Redescends jusqu’aux bras presque tendus.  
Erreur fréquente : Siège trop haut : les épaules soulèvent la charge.  
Si la machine est prise : Curl biceps à la poulie basse

### Triceps à la machine (dips assis)

**Dips assis à la machine** · Triceps, bas des pectoraux · Débutant  
Réglages : Siège réglé pour que les poignées soient à hauteur des côtes.  
Consignes : Dos contre le dossier, épaules basses. / Pousse vers le bas jusqu’aux bras tendus. / Remonte lentement jusqu’aux coudes à 90°.  
Erreur fréquente : Laisser remonter trop haut : les épaules partent vers l’avant.  
Si la machine est prise : Extension des triceps à la corde

### Machine à abdominaux

**Crunch à la machine** · Grand droit de l’abdomen · Débutant  
Réglages : Siège réglé pour que les poignées ou coussins soient à hauteur d’épaules. Charge légère pour commencer.  
Consignes : Pieds calés, dos contre le dossier. / Enroule le buste en soufflant, côtes vers le bassin. / Reviens lentement sans laisser la charge reposer.  
Erreur fréquente : Tirer avec les bras au lieu d’enrouler le ventre.  
Si la machine est prise : Crunch à genoux à la corde

### Machine à lombaires

**Extension lombaire à la machine** · Muscles du bas du dos, fessiers · Débutant  
Réglages : Dossier réglé à hauteur des omoplates, pieds calés. Charge légère.  
Consignes : Bras croisés sur la poitrine. / Pousse le dossier vers l’arrière jusqu’au buste droit. / Ne pas dépasser la position droite.  
Erreur fréquente : Aller loin en arrière en cambrant fort.  
Si la machine est prise : Extension lombaire au banc à 45°

### Banc à lombaires (45°)

**Extension lombaire au banc à 45°** · Bas du dos, fessiers, ischio-jambiers · Débutant  
Réglages : Coussin réglé juste sous le pli de l’aine, chevilles calées sous les rouleaux.  
Consignes : Descends le buste dos plat. / Remonte jusqu’à l’alignement jambes-buste. / Serre les fessiers en haut, sans cambrer.  
Erreur fréquente : Remonter au-delà de l’alignement en creusant le dos.  
Si la machine est prise : Bird dog

### Tractions et dips assistés

**Traction assistée** · Grand dorsal, biceps · Débutant  
Réglages : Plus la charge est lourde, plus la machine t’aide. Genoux sur la plateforme une fois les mains sur la barre.  
Consignes : Mains un peu plus larges que les épaules. / Tire la poitrine vers la barre, coudes vers les hanches. / Redescends jusqu’aux bras tendus.  
Erreur fréquente : Monter et descendre vite : la plateforme rebondit et fait le travail.  
Si la machine est prise : Tirage vertical

**Dips assistés** · Triceps, bas des pectoraux, épaules · Intermédiaire  
Réglages : Charge d’assistance réglée, genoux sur la plateforme, mains sur les barres parallèles.  
Consignes : Buste légèrement penché en avant. / Descends jusqu’aux coudes à 90°, pas plus bas. / Pousse jusqu’aux bras tendus.  
Erreur fréquente : Descendre trop bas : l’avant de l’épaule force.  
Si la machine est prise : Dips assis à la machine

### Double poulie réglable (vis-à-vis)

Consignes : Buste légèrement penché, un pied devant. / Ramène les mains devant le bas de la poitrine, coudes légèrement fléchis. / Ouvre lentement jusqu’à la ligne des épaules.

Si la machine est prise : Dips assis à la machine

Si la machine est prise : Curl biceps à la machine

**Élévation latérale à la poulie** · Milieu des épaules · Intermédiaire

**Face pull** · Arrière des épaules, haut du dos, rotateurs · Débutant

Erreur fréquente : Plier les coudes : l’exercice devient un tirage des triceps.

**Rowing un bras à la poulie** · Grand dorsal, milieu du dos · Débutant

Erreur fréquente : Tourner le buste pour tirer.  
Si la machine est prise : Rowing assis

**Bûcheron à la poulie** · Obliques, gainage · Intermédiaire

Consignes : Bras presque tendus. / Descends en diagonale vers la hanche opposée en tournant le buste. / Pivote sur le pied arrière, reviens lentement.

Si la machine est prise : Planche latérale

**Extension de hanche à la poulie basse** · Grand fessier · Débutant  
Réglages : Poulie en position basse, sangle de cheville.

**Oiseau aux poulies croisées** · Arrière des épaules · Intermédiaire

### Smith machine

**Squat à la Smith machine** · Quadriceps, fessiers · Intermédiaire  
Réglages : Barre à hauteur d’épaules. Pieds légèrement en avant de la barre, largeur d’épaules. Crochets de sécurité réglés juste sous la position basse.  
Consignes : Barre sur le haut du dos, pas sur la nuque. / Descends en poussant les fesses en arrière, genoux dans l’axe des pieds. / Remonte en poussant dans tout le pied.  
Erreur fréquente : Pieds sous la barre : les talons décollent et les genoux avancent trop.  
Si la machine est prise : Presse à cuisses

**Fente à la Smith machine** · Quadriceps, fessiers · Intermédiaire  
Réglages : Barre à hauteur d’épaules, un grand pas d’écart entre les pieds.  
Consignes : Buste droit sous la barre. / Descends le genou arrière vers le sol. / Pousse sur la jambe avant pour remonter.  
Erreur fréquente : Pas trop court : le genou avant dépasse largement la pointe.  
Si la machine est prise : Fentes arrière

**Développé couché à la Smith machine** · Pectoraux, épaules, triceps · Intermédiaire  
Réglages : Banc plat sous la barre, la barre au-dessus du bas de la poitrine. Crochets de sécurité réglés juste au-dessus de la poitrine.  
Consignes : Omoplates serrées, pieds au sol. / Descends la barre vers le bas de la poitrine. / Pousse jusqu’aux bras presque tendus.  
Erreur fréquente : Banc mal placé : la barre descend vers le cou.  
Si la machine est prise : Développé assis à la machine

**Développé incliné à la Smith machine** · Haut des pectoraux, épaules · Intermédiaire  
Réglages : Banc incliné à 30°, barre au-dessus du haut de la poitrine.  
Consignes : Omoplates serrées. / Descends la barre vers le haut de la poitrine. / Pousse sans décoller les fesses.  
Erreur fréquente : Banc trop incliné : ce sont les épaules qui travaillent.  
Si la machine est prise : Développé incliné à la machine

**Développé épaules assis à la Smith machine** · Épaules, triceps · Intermédiaire  
Réglages : Banc à dossier droit, barre devant le visage.  
Consignes : Dos contre le dossier. / Descends la barre au niveau du menton. / Pousse au-dessus de la tête.  
Erreur fréquente : Descendre la barre derrière la nuque.  
Si la machine est prise : Développé épaules à la machine

**Rowing buste penché à la Smith machine** · Dos, arrière des épaules, biceps · Intermédiaire

**Hip thrust à la Smith machine** · Grand fessier, ischio-jambiers · Intermédiaire

**Soulevé de terre jambes tendues à la Smith machine** · Ischio-jambiers, fessiers · Intermédiaire

Consignes : Genoux légèrement fléchis. / Pousse les fesses en arrière, la barre frôle les cuisses. / Remonte en serrant les fessiers, dos plat.

### Hack squat

**Hack squat** · Quadriceps, fessiers · Intermédiaire  
Réglages : Épaulières à une hauteur où tu peux te glisser dessous jambes presque tendues. Pieds au milieu de la plateforme. Poignées de sécurité à tourner pour libérer la machine.  
Consignes : Dos et tête contre le dossier. / Descends jusqu’à 90° aux genoux, genoux dans l’axe des pieds. / Pousse dans tout le pied jusqu’aux jambes presque tendues.  
Erreur fréquente : Laisser les talons décoller en bas.  
Si la machine est prise : Presse à cuisses

### Tapis de course

**Marche inclinée sur tapis** · Cœur, mollets, fessiers · Débutant  
Réglages : Vitesse de marche (4 à 6 km/h), pente de 5 à 12 %. Pince de sécurité accrochée au vêtement.  
Consignes : Buste droit, sans te tenir aux barres. / Pas naturels, pied entier au sol. / Augmente la pente avant la vitesse.  
Erreur fréquente : Se tenir aux barres : l’effort chute.  
Si la machine est prise : Escalier

**Course sur tapis** · Cœur, jambes · Débutant  
Réglages : Pente de 1 % pour rapprocher de la course dehors. Pince de sécurité accrochée.  
Consignes : Cours au centre du tapis. / Petits pas rapides, regard droit. / Change la vitesse avec les touches, sans sauter sur les côtés.  
Erreur fréquente : Courir trop près de la console : on raccourcit le pas.  
Si la machine est prise : Vélo elliptique

### Vélo elliptique

**Vélo elliptique** · Cœur, jambes, bras · Débutant  
Réglages : Résistance assez forte pour ne pas « tourner dans le vide ».  
Consignes : Pieds à plat sur les pédales. / Pousse et tire les poignées. / Buste droit, sans t’appuyer.  
Erreur fréquente : Résistance trop faible : les jambes s’emballent.  
Si la machine est prise : Marche inclinée sur tapis

### Vélo droit

**Vélo droit** · Cœur, quadriceps, fessiers · Débutant  
Réglages : Selle à hauteur de hanche debout : jambe presque tendue en bas du coup de pédale. Pieds dans les cale-pieds.  
Consignes : Bassin stable sur la selle. / Cadence de 80 à 95 tours par minute. / Monte la résistance plutôt que la cadence.  
Erreur fréquente : Selle trop basse : les genoux remontent et fatiguent.  
Si la machine est prise : Vélo semi-allongé

### Vélo semi-allongé

**Vélo semi-allongé** · Cœur, quadriceps, fessiers · Débutant  
Réglages : Siège avancé ou reculé pour que la jambe soit presque tendue en bas.  
Consignes : Dos contre le dossier. / Pousse les pédales sans décoller le bassin. / Cadence régulière.  
Erreur fréquente : Siège trop près : genoux très pliés.  
Si la machine est prise : Vélo droit

### Rameur

**Rameur** · Cœur, jambes, dos, bras · Intermédiaire  
Réglages : Pieds calés, sangle sur le haut du pied. Volet de résistance (damper) entre 3 et 5.  
Consignes : Ordre : jambes, puis buste, puis bras. / Retour dans l’ordre inverse : bras, buste, jambes. / Le retour dure deux fois plus longtemps que la poussée.  
Erreur fréquente : Tirer avec les bras avant d’avoir poussé avec les jambes.  
Si la machine est prise : Vélo à air

### Escalier (stair climber)

**Escalier** · Cœur, fessiers, quadriceps, mollets · Intermédiaire  
Réglages : Niveau bas pour commencer (marches lentes).  
Consignes : Pied entier sur la marche. / Buste droit, mains légères sur les rampes. / Rythme régulier.  
Erreur fréquente : Se pencher sur les rampes en portant son poids.  
Si la machine est prise : Marche inclinée sur tapis

### Vélo à air (air bike)

**Vélo à air** · Cœur, corps entier · Intermédiaire  
Réglages : Selle réglée comme un vélo droit. Plus tu pédales fort, plus ça résiste.  
Consignes : Pousse et tire les poignées en rythme avec les jambes. / Bassin stable. / Pour les sprints : départ progressif sur deux à trois secondes.  
Erreur fréquente : Partir à fond dès la première seconde.  
Si la machine est prise : Rameur

### SkiErg

**SkiErg** · Cœur, dos, bras, gainage · Intermédiaire  
Réglages : Volet de résistance entre 3 et 5. Pieds largeur de hanches.  
Consignes : Bras en haut, tire vers le bas en pliant légèrement les hanches. / Mains qui passent près des cuisses. / Remonte en te redressant.  
Erreur fréquente : Tirer seulement avec les bras, sans les hanches.  
Si la machine est prise : Rameur
